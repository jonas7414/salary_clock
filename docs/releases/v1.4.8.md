# v1.4.8 — 立體金幣與隨機碰撞堆疊

- 金幣改為自然、不規則的堆疊。新金幣從隨機位置落下，保留原有金幣的位置，透過碰撞與回彈堆積；接近滿堆時偏向較低的落點，避免金幣堆到畫面外。
- 金幣直徑約 12–14 像素，大小與傾角各異。幣面加入厚邊、刻紋、高光與陰影，翻轉落下和靜止時都保留立體感。
- 改善撞擊已靜止金幣堆時的回彈反應，並保留側向撞擊推動鄰幣的效果。重開機或校時後，依工時還原有支撐、不重疊的不規則金幣堆。
- 維持每個工作日 52 枚、依有效工時逐枚增加的規則；午休不增加，下班才集滿，與月薪高低無關。
- 更新 README、圖解使用手冊、三主題展示圖與碰撞動畫；新增 32 組隨機種子的還原與完整工作日回歸測試。

提供 PSRAM／無 PSRAM 兩種韌體及各自的 SHA-256 校驗檔。既有 NVS 設定、分區布局與 A/B OTA 回滾保持相容。

驗證範圍包含兩組態建置、主機回歸、發版工具檢查，以及三主題整幀／strip 渲染比對。本次未進行實板燒錄、動畫流暢度或裝置 OTA 驗證。
