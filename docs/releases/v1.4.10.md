# v1.4.10 — 休假倒數與單筆崩潰紀錄

- 休假倒數改成「天／小時／分／秒」，三種主題都保留休假日期、連假天數與進度條。
- Panic／致命錯誤進入 ESP-IDF panic handler 時，保存至固定 256 KiB Flash 分區。永遠只保留最新一筆；沒網路時，新紀錄也會覆蓋舊紀錄，不會無限累積。
- 開機透過 USB Monitor 輸出崩潰摘要，另提供 `tools/read_coredump.py` 匯出並驗證紀錄。
- 配置 Loki 憑證的私人建置：開機有網路及有效時間時先詢問是否回報；上傳包含 `device`，只有 Loki 回覆 HTTP 204 才刪除紀錄。稍後、離線或上傳失敗都保留單筆紀錄，不持續重試。
- 保留 v1.4.9 的下班貓咪動畫；更新使用手冊與三主題預覽。

**公開韌體不含 Loki Token，因此不啟用雲端回報彈窗；崩潰保存與 USB 讀取仍可使用。** 可依 [崩潰診斷文件](https://github.com/jonas7414/salary_clock/blob/v1.4.10/docs/crash-diagnostics.md) 配置私人建置。

**舊裝置需 USB 更新分區表，才能啟用崩潰保存。** 一般 OTA 只更新 application，不會新增分區；尚未更新分區表時，其他功能仍可正常使用。NVS 設定與兩個 A/B 槽位保持相容，不需要 erase-flash。

提供 PSRAM／無 PSRAM 韌體及各自 SHA-256 校驗檔。驗證包含雙組態建置、主機回歸、公開產物憑證檢查，以及三主題整幀／strip 渲染比對。本次未燒錄實板，未宣稱實板 panic、斷電保存或 OTA 驗證完成。
