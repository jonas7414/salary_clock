# v1.4.4 — 我的頁面、紀念日與自主更新

- 設定頁新增頁面排序，支援拖曳及上移／下移按鈕。開機顯示第一頁；預設順序最後是系統資訊。
- 新增紀念日名稱、日期與每年重複選項，在「現在時刻」頁顯示倒數、當日提醒或已經過天數。2 月 29 日在平年以 2 月 28 日紀念。
- OTA 改為每次開機只自動檢查一次，不自行安裝。偵測到新版時提供「立即更新／稍後／此版本不再提醒」，預選稍後；BOOT 選擇、GPIO14 確認。
- 不再提醒的版本會保存，手動檢查仍可重新顯示；日後更高版本會再通知。在系統資訊頁長按 BOOT 2 秒可手動檢查，最新版會明確顯示狀態。
- 確認更新後在前景顯示下載進度條、百分比及容量，保持亮屏；完成 SHA-256 與映像驗證後才重啟。更新期間暫停其他按鍵操作。
- 確認綁定畫面上的版本，避免伺服器改版後意外安裝另一個版本。保留 A/B 回滾與既有設定。

GPIO0 平時仍是上一頁；GPIO14 短按下一頁、雙擊設定、長按五秒休眠／喚醒。

自訂名稱的小字中文字庫放在 Flash；韌體約 3.2 MB，仍符合現有 4 MiB OTA 分區，無需更換分區表。名稱最多 24 字，建議簡短，不支援 emoji。

提供 `firmware.bin` 與 `firmware-no-psram.bin`，各附 SHA-256 校驗檔。
